# โปรแกรมตรวจสอบรอยบัดกรี SMD

**โปรเจกต์นี้รองรับเฉพาะ Windows เท่านั้น** โดยใช้ Windows 10/11 แบบ 64 บิต สำหรับเครื่อง Intel/AMD

## ติดตั้งบนเครื่องใหม่ ตั้งแต่ยังไม่มี Python

ต้องต่ออินเทอร์เน็ตขณะติดตั้ง

1. วางโฟลเดอร์โปรแกรมในตำแหน่งที่เขียนไฟล์ได้ เช่น `D:\SolderInspector` หากได้มาเป็น ZIP ให้แตกไฟล์ทั้งหมดก่อน
2. ดับเบิลคลิก **INSTALL.bat** แล้วรอจนขึ้น `Setup complete`
3. ดับเบิลคลิก **start.bat** เพื่อเปิดโปรแกรม

ตัวติดตั้งจะตรวจ Python 3.10–3.12 แบบ 64 บิตที่มี Tkinter และ venv อยู่ก่อน ถ้าไม่พบ จะดาวน์โหลด Python 3.12 รุ่นย่อยล่าสุดที่มีตัวติดตั้ง Windows จาก python.org ตรวจลายเซ็น แล้วติดตั้งเฉพาะผู้ใช้ปัจจุบันพร้อม pip และ Tkinter โดยไม่ต้องเพิ่ม PATH เอง เลือกรุ่นนี้เพื่อรองรับไลบรารี OCR ของโปรแกรม
จากนั้นติดตั้ง Microsoft Visual C++ Runtime หากยังไม่มี สร้างสภาพแวดล้อม `.venv` และลงไลบรารีกล้อง ภาพ OCR การแสดงทรัพยากร และ AI ทั้งหมด
Windows อาจขอสิทธิ์ผู้ดูแลระบบสำหรับ Microsoft Runtime ให้กดยอมรับเพื่อดำเนินการ
วิธีติดตั้ง Python อ้างอิง [คู่มือ Python สำหรับ Windows](https://docs.python.org/3.12/using/windows.html#installing-without-ui)

โปรแกรมเลือก PyTorch สำหรับ NVIDIA อัตโนมัติเมื่อพบ GPU พร้อมไดรเวอร์ มิฉะนั้นใช้รุ่น CPU
ใช้ PyTorch 2.8.0, torchvision 0.23.0 และ Ultralytics 8.4.175 ตามรุ่นที่ใช้ตรวจสอบโมเดลในโปรเจกต์
แพ็กเกจ NVIDIA ใช้ CUDA 12.8 ที่มากับ PyTorch ไม่ต้องติดตั้ง CUDA Toolkit แยก แต่เครื่องต้องมีไดรเวอร์ NVIDIA ที่รองรับ
หากติดตั้งแพ็กเกจ NVIDIA แล้ว CUDA ใช้ไม่ได้ โปรแกรมยังตรวจด้วย CPU ได้ และแจ้งอุปกรณ์ที่ใช้หลังติดตั้ง
ดาวน์โหลดแพ็กเกจจาก [ช่องทางทางการของ PyTorch](https://pytorch.org/get-started/previous-versions/)

การติดตั้งครั้งแรกอาจดาวน์โหลดหลาย GB โดยเฉพาะรุ่น NVIDIA และต้องมีพื้นที่ว่างสำหรับแพ็กเกจและประวัติภาพ
หากดาวน์โหลดไม่สำเร็จ ให้ตรวจอินเทอร์เน็ตแล้วเปิด INSTALL.bat ซ้ำ
หาก `.venv` ที่ย้ายจากเครื่องอื่นใช้ไม่ได้ ให้เปลี่ยนชื่อเป็น `.venv-old` แล้วเปิด INSTALL.bat ใหม่
เมื่อนำโปรแกรมไปเครื่องอื่น ให้คัดลอกโฟลเดอร์โดยไม่ต้องคัดลอก `.venv` แล้วติดตั้งใหม่บนเครื่องปลายทาง

## ไฟล์ที่ใช้เปิดและติดตั้ง

| ไฟล์ | หน้าที่ |
|---|---|
| INSTALL.bat | ติดตั้งครบตั้งแต่ Python ถึงไลบรารี AI |
| setup.bat | ตัวติดตั้งเดียวกับ INSTALL.bat |
| start.bat | เปิดโปรแกรม และเรียกติดตั้งอัตโนมัติหากยังไม่มี Python ของโปรเจกต์หรือขาดไลบรารี |
| install_cuda.bat | ติดตั้งแพ็กเกจ NVIDIA CUDA โดยตรง |
| install_ai.bat | ติดตั้งครบเช่นเดียวกับ INSTALL.bat รองรับชื่อไฟล์เดิม |
| install.ps1 | ขั้นตอนตรวจ ดาวน์โหลด ติดตั้ง และทดสอบหลังติดตั้ง |

หากต้องการเลือก CPU เอง เปิด PowerShell ในโฟลเดอร์แล้วรัน

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Acceleration CPU
```

ตรวจไลบรารี หน้าต่าง GPU และการอ่านโมเดลที่มีอยู่ โดยไม่ติดตั้งเพิ่ม

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -CheckOnly
```

บันทึกการติดตั้งอยู่ใน `logs/setup/` หากล้มเหลวให้อ่านข้อความท้ายหน้าต่างและไฟล์ log ล่าสุด
`requirements.txt` เป็นไลบรารีพื้นฐาน และ `requirements-ai.txt` รวมไลบรารี AI
`requirements-lock.txt` เป็นรายการรุ่นจากเครื่องพัฒนาที่ใช้ NVIDIA สำหรับอ้างอิง ตัวติดตั้งเลือกแพ็กเกจ CPU/NVIDIA ให้เอง

## เริ่มตรวจบอร์ด

- วางโมเดลตรวจรอยบัดกรีชื่อ `best_inspec.pt` และโมเดลหาอุปกรณ์ชื่อ `best_locator.pt` ไว้ข้าง `app.py`
- เปิด `start.bat` โปรแกรมจะพยายามเชื่อมต่อ **USB 2.0 Camera** อัตโนมัติ ปิดโปรแกรมอื่นที่กำลังใช้กล้องก่อน
- ปรับกล้อง รุ่นโมเดล Confidence ขา IC และด้านไดโอดใน **ตั้งค่าโปรแกรม** โปรแกรมจำค่าใน `settings.json`
- โปรแกรมตรวจภาพล่าสุดต่อเนื่อง ไม่ต้องรอให้บอร์ดหยุด และไม่หน่วงการรับกรอบ locator
- U1 มี 14 ขา U4 มี 28 ขา ต้องตั้งจุดอ้างอิงขา 1 และเลื่อนเก็บภาพแต่ละฝั่ง รายละเอียดใน **REALTIME_GUIDE_TH.md**
- คลิกอุปกรณ์บนผังบอร์ดเพื่อดูภาพหลักฐานและรายละเอียดผลตรวจ
- กรอกเลขประจำบอร์ด แล้วกด **บันทึกผลบอร์ดนี้** เมื่อสแกนและตรวจครบทุกอุปกรณ์ บันทึกบอร์ด FAIL ได้ด้วย
- เมื่อบันทึกสำเร็จ โปรแกรมจะเริ่มบอร์ดใหม่และล้างเลขบอร์ดให้กรอกใหม่
- เปิดแท็บ **ประวัติบอร์ดที่ตรวจเสร็จ** เพื่อดูบอร์ดจำลอง ภาพแต่ละอุปกรณ์ ผล PASS/FAIL และเหตุผล

## ไฟล์ที่ต้องเก็บ

- `.venv` เป็นไลบรารีที่ติดตั้งบนเครื่องนี้ ลบได้เมื่อต้องการติดตั้งใหม่ แต่ไม่ต้องนำไปอีกเครื่อง
- `assets` เป็นภาพประกอบและข้อมูลแหล่งที่มา
- `calibrations` เป็นภาพและตำแหน่งอ้างอิงขา IC/ขั้วไดโอด
- `logs` เป็นผลตรวจ หลักฐาน ประวัติบอร์ด และบันทึกการติดตั้ง
- `settings.json` เป็นค่าตั้งส่วนตัว และไฟล์ `.pt` เป็นโมเดลที่ฝึกแล้ว
- `tests` เป็นชุดตรวจสอบการทำงานของโปรแกรม

ไฟล์ฝึกโมเดล Notebook ชุดทดลอง และไฟล์สำรองที่ไม่เกี่ยวกับการใช้งานตรวจสอบถูกนำออกจากโปรเจกต์นี้แล้ว
ดูวิธีใช้กล้อง การสะสมผลขา IC และขั้วไดโอดเพิ่มเติมใน **REALTIME_GUIDE_TH.md**
